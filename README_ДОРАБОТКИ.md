# Доработки пользовательской части SubControl

Добавлены отдельные окна «Аналитика», «Календарь», «Бюджет», «История изменений», доступные из блока на главной странице.

В разделе подписок появилась кнопка «+ Своя подписка». Личный тариф привязывается к своему владельцу и скрывается из общего каталога. Через меню «⋮» активной подписки можно приостановить её, возобновить, изменить следующую дату оплаты; стоимость можно изменить только для личного тарифа (чтобы не менять общий тариф для всех пользователей).

В настройках появился выбор срока напоминания (от 1 до 30 дней). Месячный бюджет сохраняется в уже существующих пользовательских настройках.

Приложение использует существующую базу MySQL. При первом входе пользователя создаётся дополнительная таблица `personal_plans` (через `Repository.ensure_preferences`). Для работы с личной подпиской в таблице `categories` должна существовать хотя бы одна категория.

Панели менеджера и администратора не изменялись. Реальное списание денежных средств не выполняется — в проекте осталась учебная симуляция.

## Запуск

Используйте существующий `RUN.bat` и инструкции `README.md`. Необходимы MySQL, настроенное подключение и зависимости из `requirements.txt`.

## Проверка

Синтаксис Python-файлов проверен. Полноценный запуск интерфейса и интеграционные тесты здесь не выполнялись (нет PyQt6 и подключённой MySQL), поэтому перед защитой проверьте сценарии с реальной базой.
