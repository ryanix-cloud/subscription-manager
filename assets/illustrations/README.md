# Иллюстрации SubControl

Созданы встроенным инструментом image_gen по навыку imagegen для пользовательской части курсовой Ани.
Сохранены в проекте с прозрачностью; при запуске интернет не требуется.

- `finance.png`: главная страница и небольшое изображение в сводке аккаунта.
- `notifications.png`: карточка настройки уведомлений.

Изображения занимают отдельные области, не перекрывают текст и не перехватывают нажатия.

## Итоговые промпты

### finance.png

Use case: stylized-concept. Asset type: transparent illustration for a subscription budget desktop app. Create a refined, soft 3D still-life: a small blush-pink ceramic piggy bank, two slim rounded subscription cards without writing, and three rose-gold coins. One tiny raspberry flower-like sparkle. Restrained editorial product illustration, smooth matte clay, gentle studio highlights, subtle contact shadow only. Palette blush rose #F7CAD9, pink #FF73A2, raspberry #B82C63 and soft ivory. Square composition, centered object group, comfortable transparent padding, clean silhouette legible at 150 pixels. Genuine transparent background. No background scene, no lettering, no logos, no numerals, no frame, no watermark. Calm, mature, charming, not crowded.
