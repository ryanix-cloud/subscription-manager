# Как показать учебную оплату

Приложение работает только с существующей MySQL `submanager`. При запуске новой
версии ожидаемые платежи с наступившей датой получают учебные ответы, которые
сохраняются в этой базе. Пока приложение закрыто, проверки не выполняются.

1. Откройте «Платежи» и найдите платёж со статусом «Ожидается». Для управляемого
   показа можно взять будущий платёж: автоматическая проверка его ещё не трогает,
   а учебную оплату вручную можно выполнить заранее.
2. В меню строки выберите «Учебная оплата», затем сценарий «Недостаточно средств»
   и запустите оплату. Появится причина отказа. Чек и продление не создаются.
3. В этом же окне выберите успешный сценарий и повторите оплату. После ответа
   появится номер автоматически сформированного чека и кнопка его сохранения.
4. Закройте диалог. В деталях платежа видны обе попытки. Статус стал успешным,
   создан следующий ожидаемый платёж. Через меню можно открыть чек или сохранить
   его копию в выбранную папку.

Для автоматического сценария добавьте подписку через каталог. Её первый платёж
назначен на сегодня, поэтому ответ приходит сразу после добавления. Дальнейшие
проверки выполняются раз в минуту либо кнопкой «Проверить списания». При отказе
нужна явная команда «Повторить оплату».

Случайный сценарий даёт 80% успешных ответов. Для защиты удобнее выбирать исход
явно. Данные карты не требуются, деньги не списываются, связи с реальными
сервисами нет. Каждая попытка имеет уникальный идентификатор; повтор одного
ответа не создаёт второй чек и не продлевает подписку повторно.
